Q-Point (Quiescent Point) in Transistor Circuits

The quiescent point (Q-point) is the steady-state DC operating point of a transistor circuit when no AC input signal is applied. It sets the baseline DC voltage and current levels to ensure proper operation.

Key Differences Between BJT and MOSFET Q-Points

Feature BJT Q-Point MOSFET Q-Point
Control Parameter Base Current (IB) Gate-to-Source Voltage (VGS)
Key Current Collector Current (IC) Drain Current (ID)
Key Voltage VCE VDS

BJT Q-Point

  • Variables: VCE, IC

IC = β × IB

VCE = VCC − (IC × RC)

  • Ideal: VCE ≈ VCC / 2
  • Used in Active Region

MOSFET Q-Point

  • Variables: VDS, ID

ID = ½ μn Cox (W/L) (VGS − Vth)²

VDS = VDD − (ID × RD)

  • Condition: VDS > (VGS − Vth)
  • Gate current ≈ 0

Why Q-Point Matters

  • Prevents distortion
  • Controls power consumption

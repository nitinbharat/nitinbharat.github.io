Meaning of Quiescent

Quiescent means "at rest" or "inactive state". It refers to a condition where a system is powered ON but not processing any input signal.

In electronics, quiescent refers to the DC steady state of a circuit when no AC signal is applied.

Quiescent in LDO / Linear Regulators

In an LDO (Low Dropout Regulator) or linear regulator, quiescent current (Iq) is the small current consumed by the regulator itself to operate internal circuits, even when there is no load or very small load.

  • Quiescent current is the standby current drawn by the regulator IC.
  • Lower quiescent current leads to better battery life in portable devices.

Quiescent Point (Q-Point)

The quiescent point (Q-point) is the steady-state DC operating point of a transistor circuit when no AC input signal is applied. It sets the baseline DC voltage and current levels to ensure proper amplification.

Key Differences Between BJT and MOSFET Q-Points

Feature BJT Q-Point MOSFET Q-Point
Control Parameter Base Current (IB) Gate-to-Source Voltage (VGS)
Key DC Current Collector Current (IC) Drain Current (ID)
Key DC Voltage Collector-Emitter Voltage (VCE) Drain-to-Source Voltage (VDS)
Linear Region Active Region Saturation Region

BJT Q-Point Parameters

For a BJT amplifier, the Q-point must be in the Active Region for distortion-free operation.

  • The Q-point is defined by (VCE, IC).
  • IC = β × IB
  • VCE = VCC - (IC × RC)
  • Ideal VCE is VCC / 2 for maximum signal swing.
  • Q-point stability is important because β varies with temperature.

MOSFET Q-Point Parameters

For MOSFET amplifiers, the Q-point is set in the Saturation Region.

  • The Q-point is defined by (VDS, ID).
  • ID = (1/2) μn Cox (W/L) (VGS - Vth)²
  • VDS = VDD - (ID × RD)
  • Condition: VDS > (VGS - Vth)
  • Gate current is approximately zero, making biasing simpler than BJT.

Why Q-Point Biasing Matters

  • Prevents distortion in amplified signals.
  • Ensures correct operation region.
  • Controls idle power consumption.
